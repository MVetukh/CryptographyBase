# CryptographyBase

## Основные возможности проекта

### Модуль math/

#### Математические основы криптографии:

- расширенный алгоритм Евклида, модульные инверсии;

- тесты простоты (Miller–Rabin);

- арифметика в полях GF(2ⁿ);

- построение S-boxes и линейных преобразований.

### Модуль block/

#### Блочные шифры и режимы:

- учебные SPN/Feistel-структуры;

- безопасные обёртки над AES (через PyCA / PyCryptodome);

- CBC, CTR, GCM/AEAD (включая корректную обработку nonce/IV).

### Модуль asym/

#### Асимметрическая криптография:

- RSA: генерация ключей, шифрование, подпись;

- ECDH/ECDSA/Ed25519: ключи, совместные секреты, подписи;

- сравнение производительности RSA vs ECC.

### Модуль pki/

#### PKI-инфраструктура:

- генерация корневого CA;

- создание CSR и выпуск сертификатов;

- проверка цепочек, сроки действия, политика ротации.

### examples/ (Jupyter Notebooks)

#### Практические эксперименты:

- анализ S-box построений;

- демонстрация корректного/некорректного использования nonce в GCM;

- сравнение AEAD-режимов;

- разбор TLS 1.3 handshake (PCAP → разбиение сообщений)
